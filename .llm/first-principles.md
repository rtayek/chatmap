# First Principles

## Core Philosophy
- **Transient Data Isolation:** Conversation histories, debug cycles, and raw transcripts are temporary diagnostic logs, not core project knowledge. They must be walled off to protect the context window from chronological bloat.
- **Semantic Compression:** Project memory must store distilled facts, invariants, boundaries, and active models. General programming concepts are omitted because the LLM already possesses them.
